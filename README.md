# GPT CLI

CLI đầu tiên của mình được viết bằng **Python** và **Typer** để học cách xây dựng các ứng dụng dòng lệnh.

## 📖 Giới thiệu

GPT CLI là một dự án học tập giúp mình làm quen với:

- Python
- Typer
- Command Line Interface (CLI)
- setup.py
- pip install
- GitHub

Dự án được tạo với mục đích học lập trình và tìm hiểu cách hoạt động của các công cụ như Git, npm và Vercel CLI.

## ✨ Tính năng

Hiện tại CLI hỗ trợ các lệnh:

- hello
- about
- version

- logout
- add
- multiply
- age
- calc
- me

## 📦 Cài đặt

Clone dự án:

```bash
git clone https://github.com/namnn2016-ops/CLI
```

Di chuyển vào thư mục:

```bash
cd gpt
```

Cài đặt:

```bash
python -m pip install -e .
```

---

## 🚀 Cách sử dụng

### Xin chào

```bash
gpt hello Nam
```

Kết quả:

```text
Hello Nam!
```

---

### Cộng hai số

```bash
gpt add 10 20
```

Kết quả:

```text
30
```

---

### Nhân hai số

```bash
gpt multiply 7 8
```

Kết quả:

```text
56
```

---

### Hiển thị phiên bản

```bash
gpt version
```

Kết quả:

```text
1.0.0
```

---

### Giới thiệu

```bash
gpt about
```

---

### Đăng nhập

```bash
gpt login
```

---

### Đăng xuất

```bash
gpt logout
```

---

### Hiển thị thông tin

```bash
gpt me
```
